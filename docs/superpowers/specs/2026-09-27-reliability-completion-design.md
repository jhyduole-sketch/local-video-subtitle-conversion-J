# 本地字幕工具优化收尾设计

用户已要求完成上一轮审查列出的全部优化并自行测试，过程中的常规决定由实现者处理。

1. Web：仅访问服务端登记的输出目录；校验 Host/Origin；局域网启动须配置访问令牌，浏览器凭据放 HttpOnly cookie，避免 URL 携带令牌。JSON 和视频上传有限额、读取超时、磁盘检查；上传与任务绑定，任务结束后清理，启动时清除过期孤儿文件。
2. 来源：检查语言脚本、时间有效性、空白和重复；读取匹配语言的内置轨道；自动模式按成本顺序评估，保留候选，必要时比较后选取较优可用来源。手动模式保持来源，非空低质量结果提示警告。
3. 翻译：统一记录跳过、失败、成功的引擎尝试，优先类型化失败分类，取消立即传播，跨引擎回退保留已完成翻译；兼容原有翻译缓存。
4. 设置：严格解析布尔、枚举、路径字符串和容量，拒绝非法值，不保存敏感字段。
5. 预估：未知时长显示未知，按阶段缓存和引擎区分估算，记录本机历史实际耗时用于后续校准，展示范围与依据。
6. 缓存：完整文件内容指纹和明确版本身份；清理与运行任务互斥，缓存汇总容忍文件同时消失。
7. 结构：抽取输入准备、来源选择、翻译编排和 Web 安全/上传服务，保留兼容入口；首次运行提供可执行依赖指导，清楚说明当前平台能力。
8. 验收：新增行为回归测试、完整 unittest、Python/JS 语法检查、真实 FFmpeg 短片与多轨字幕烟测。重模型/外部云端需现有资源可用才运行，不下载大模型或引入收费调用。

在现有工作区实施，保留已有未提交代码；不自动提交或推送。接口兼容允许安全性要求导致不受信任路径及非法设置被拒绝。
